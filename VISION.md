# metaprev vision

metaprev helps developers, content authors, and coding agents catch broken
share metadata before sharing a page. It inspects the actual page and image,
explains observed compatibility risks, and creates a local repair workspace.
Success means evidence-led fixes and consistent findings across CLI, JSON, HTML,
and a public web inspector. The CLI keeps local inspection on the user's machine.

## Scope

Fetch local or deployed HTTP(S) pages; parse Open Graph and X metadata;
validate image facts and fallbacks; show representative platform cards,
crop evidence, themes, and copy-ready repairs. Keep stable issue codes and
exit behavior suitable for CI. Treat page-controlled input as untrusted.

## Non-goals

Exact third-party rendering or cache guarantees, generic SEO copy-length
advice, invented metadata, and social-media management are outside the product.

## Public website

The owner authorized a website on 24 October 2026. Visitors enter a public URL
and receive observed Open Graph and X metadata, representative social cards,
and factual findings. The website rejects private networks and credentials.
It does not execute page scripts or promise a platform's final rendering.

The landing page and field-specific guides explain the tool in server-rendered
HTML. Search and answer engines receive the same visible facts and source links.
The first release has no advertising or tracking scripts. Advertising is a later
revenue option after the public tool and hosting are established.
